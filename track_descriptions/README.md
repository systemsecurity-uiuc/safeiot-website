## Changes made since the import

Formatting and shared wording were synced across the two tracks; the research and technical content
of each track was left alone.

- Section structure is now identical: same headings, same order, everything in bullet lists.
  Track 1 was written in paragraphs and has been converted.
- Headings unified: "Submission Requirements", "Judging Criteria",
  "Scientific Paper (Up to 5 Pages)", "Pitch Video Presentation (Maximum 5 Minutes)".
- Potential Categories turned from a run-on paragraph into a numbered list in both tracks, both
  introduced with "include but are not limited to the following".
- Page limit: Track 1 now follows Track 2's rule — 5 pages for the main body, 7 including references
  and appendices. Track 1 previously left the total length uncapped. This also matches what the
  website and the submission form already tell participants.
- ACM format sentence is now one shared sentence carrying both the page rule (from Track 2) and the
  font/margin/bibliography wording (from Track 1), with both template links.
- Slide template link filled into Track 1; both tracks now point at the same template.
- License wording: Track 1 now matches Track 2 and the website — permissive licenses recommended
  (MIT, Apache 2.0, BSD). It previously said "an established open-source license".
- Repository requirements share the fuller Track 1 phrasing for setup, reproducibility, and baselines.
- Video requirements: both now ask for the evaluation to be covered, which only Track 1 mentioned.
- Impact Potential: Track 2 gained the "run within or contribute to the SafeIoT continuous pipeline"
  bullet, which only Track 1 had, and the fuller wording about contributing reusable artifacts.
- Track 2's paper section: fixed an unclosed parenthesis, and the stray "wrong/missing license
  information" line is now a normal taxonomy entry.
- Google Docs export artifacts cleaned up throughout.
- Both tracks now open their Submission Requirements with the deadline and a pointer to
  https://safe-iot.com/#hackathon for how to submit and everything else.

## Open questions

   has no equivalent of Track 1's "show how the approach advances beyond existing tools". Worth
   adding for symmetry, but it needs Track-2-specific wording, so it is left alone for now.
2. **Track 1 asks twice for confirmed / needs-review / unverifiable findings to be distinguished** —
   once under GitHub Repository and once under Clarity and Presentation. Track 2 asks only under
   Clarity. Either drop the repository bullet from Track 1 or add the equivalent to Track 2.
3. **One slide template for both tracks?** Track 1's placeholder was filled with Track 2's template
   link on the assumption that it is shared. If Track 1 should have its own, the link needs replacing.
